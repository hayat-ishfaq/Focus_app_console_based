# QUICK START GUIDE
## Focus & Productivity App

### 🚀 How to Run

The application is already compiled! Simply run:

```powershell
.\build\FocusApp.exe
```

Or double-click `FocusApp.exe` in the `build` folder.

---

### 🎮 Controls Guide

#### **MAIN MENU**
- **↑ / ↓** - Navigate menu items
- **Enter** - Select item
- **ESC** - Exit app

#### **FOCUS TIMER**
1. Select duration with **↑ / ↓**
2. Press **Enter** to start
3. While running:
   - **P** - Pause/Resume
   - **S** - Stop timer
   - **ESC** - Stop and return to menu

#### **TASK MANAGER**
- **A** - Add new task
  - Type your task
  - **Enter** to save
  - **ESC** to cancel
- **M** - Manage tasks
  - **↑ / ↓** - Select task
  - **C** - Mark as complete
  - **D** - Delete task
  - **ESC** - Back

#### **STATISTICS**
- View your focus stats
- **ESC** - Back to menu

#### **BLOCK SCREEN**
- Informational only
- **ESC** - Back to menu

✅ **Pomodoro Timer** - 25/40/60 minute focus sessions

### 📁 Data Files

The app creates two files:
- `tasks.dat` - Your task list
- `stats.dat` - Your focus session history

These are created automatically when you use the app.

### 🎯 Your First Session

1. Run `.\build\FocusApp.exe`
2. Navigate to **Focus Timer** (↓ then Enter)
3. Select **25 Minutes** (Enter)
4. Stay focused until the timer completes!
5. View your achievement in **Statistics**
